# Hotel do Ceará

Sistema desktop de gerenciamento de hospedagem, desenvolvido para a disciplina **Orientação a Objetos** do **Prof. Henrique Moura** (UnB).

## Finalidade

Simular a rotina de um hotel: cadastro de clientes e funcionários, controle de quartos, registro de hospedagens e lançamento de gastos dos hóspedes. O projeto aplica herança, polimorfismo, composição, associação e dependência, com modelagem em UML no padrão ECB.
